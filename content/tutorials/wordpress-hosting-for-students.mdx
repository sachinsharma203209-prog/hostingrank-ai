## Hosting on a student budget

As a student you probably want to learn WordPress, run a portfolio, or build a class project — without paying much. The good news: hosting is cheap enough that the free tiers are rarely worth their downsides. A real WordPress site can run for **$2–5/mo**, and there are honest ways to get close to free.

## The free options (and their real costs)

| Option | Price | The catch |
| --- | --- | --- |
| Free tier hosts (InfinityFree, etc.) | $0 | No email, slow, ads, data limits, no custom domain |
| WordPress.com free | $0 | Subdomain, ads, no plugins, 1GB |
| GitHub Pages + static | $0 | Not WordPress — no PHP/database |
| VPS free tiers | $0 (time-limited) | You must admin the server; credit expires |

Free WordPress hosting exists but it's a demo, not a website you'd show an employer. The full honest breakdown is in [free WordPress hosting](/tutorials/free-wordpress-hosting).

**The student move:** use a free tier to **learn**, then spend $3/mo when you want something real. A portfolio on Hostinger costs less than a coffee a month and looks professional.

### Student discounts to check
- **GitHub Student Developer Pack** — free domain, free credits, and discounts on many dev tools (not hosting per se, but valuable)
- **Some hosts offer student pricing** — always ask before checkout

## Money-saving rules for students

1. **Watch renewal prices** — that $1.58/mo renews higher. The [cheap hosting](/tutorials/cheap-wordpress-hosting) guide exposes the real costs.
2. **Don't pay for a domain you don't need yet** — use the free subdomain while learning; buy yourname.com when the site is real.
3. **Free SSL is mandatory** — never a paid add-on. Every host in the [best WordPress hosting](/best/wordpress-hosting) list includes it.
4. **Backups are free with a plugin** — UpdraftPlus to Google Drive. See [WordPress backups](/tutorials/wordpress-backups).

## Frequently asked questions

**Is free WordPress hosting good enough for a student?**
For learning, yes. For a portfolio you'd show anyone, no — free tiers mean ads, no email, and a subdomain. $3/mo is the better investment.

**What is the cheapest WordPress hosting for students?**
Namecheap from $1.58/mo and Hostinger from $2.99/mo are the value leaders. Both include free SSL; see the [best cheap hosting](/best/cheap-hosting) rankings.

**Does the GitHub Student Pack help with hosting?**
Yes — free domain and cloud credits that can run a WordPress VPS for a while. Pair it with a cheap host for the simplest path.

**Can I run WordPress for free on a VPS?**
With cloud credits (GitHub Student Pack, trial credits), yes — but you admin the server yourself. Our [WordPress VPS](/tutorials/wordpress-vps-hosting) guide shows the setup.

**How do I start a WordPress site as a student?**
Pick a host, one-click install WordPress ([guide](/tutorials/how-to-install-wordpress)), choose a theme, and build your portfolio. Total time: an afternoon, total cost: about $3.
